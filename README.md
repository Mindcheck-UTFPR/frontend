# Mindcheck Frontend

Aplicação web do Mindcheck construída com React, TypeScript e Vite.

## Execução local

Requisitos: Node.js 22+ e pnpm 10+.

```bash
cp .env.example .env
pnpm install
pnpm dev
```

A aplicação estará em `http://localhost:5173`. Verificações: `pnpm lint`, `pnpm test` e `pnpm build`.
